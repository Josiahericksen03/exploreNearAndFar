# Explore Near & Far Travel — website mockup

Static HTML mockup for **Explore Near & Far Travel, LLC** (Faith & Rob Ericksen, Orlando, FL), based on the Five Star Solutions Group website proposal (8 pages + accessibility statement).

**Brand colors:** `#163D5A`, `#78C6D0`, `#F47A38`, `#F5C451`, `#FFF8EE`, `#2D3338`

## Preview locally

```bash
cd /Users/josiahericksen/Projects/explore-near-and-far-mockup
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).
